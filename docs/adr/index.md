# Указатель архитектурных решений

ADR — запись того, почему принято конкретное решение. Слово «принято» в старой
записи не делает всё её содержимое действующим навсегда. Читайте уточнения ниже
и актуальные [правила](../development-rules.md), [состояние](../current-state.md),
[аудит](../project-audit-2026-09-25.md). В 2026-09-25 менялись ссылки на руководство,
а не исторический смысл решений.

## Основные связи замены

| Раннее решение | Что читать сейчас |
| --- | --- |
| 0003, постоянная карта из 0013 | 0013 — волны; 0035 и 0061 — поколения и слои карты |
| Теги и стойки из 0006, 0050 | 0066 — повадки; 0081 — связки на именованных состояниях |
| Печать/повторное имя из 0011, 0048, 0070 | 0075 отменяет повторное имя; 0074 задаёт дерево специализации |
| Предел 300 уровней в ранних записях | 0058 — полоса 1–150 |
| Слоты ролей из 0025 | 0026 — свободный состав; защита из 0025 сохраняется |
| Награды 0026 и единицы вклада 0076–0077 | 0093 — участие, общий фонд и единица гильдейского дела |
| Цена дерева из 0024 | 0067 — очки и ранги; 0079 и 0083 — выучки |
| Две глубины из 0028 | 0036 и 0041 — процедурные заходы и список подземелий |
| Неизменный предел гильдии и три звания из 0030 | 0076 — рост и права; 0077 — склад, подряд и война |
| Вклад характеристик из 0058 | 0068 — сетка класса; предел уровня из 0058 остаётся |
| Три независимые ступени из 0069 | 0074 — дерево на 112 веток |
| Нет условных пассивок из 0073 | 0080 — пассивные правила; ранги продолжают менять размер |
| Общий список выучек из 0079 | 0083 — собственные выучки каждого умения |
| Границы повтора и журнала из 0009, 0012, 0044 | 0084 — одна запись ценностей, постоянный номер и версии персонажа |
| Короткая защита доставки и политика хранения из 0009, 0084 | 0085 — постоянный результат всей команды до выбора экрана |

Риски хранения из аудита A01–A08 проверяются по реализации и протоколу.
M01 уточняет границы ценностей в 0084; отметки, очередь сообщений и постоянный
общий бой реализованы M02–M03. M06 уточняет групповую награду и участие в 0093.
