# ADR 0091 — Первое дело, возвращение и полный текст

Дата: 08.10.2026. Статус: реализовано; ручная приёмка ожидается.

Уточняет [ADR 0002](0002-reply-keyboards-only.md), обучение из
[ADR 0038](0038-the-tutorial-pays.md), постоянный результат из
[ADR 0085](0085-durable-command-result.md) и экран из
[ADR 0090](0090-durable-battles-and-sessions.md). Исторические решения сохраняются.

## Причина

Начальное умение уже занимало слот и исчезало из списка второго учебного дела.
Команда следующего дела после победы только закрывала боевой экран. Повторный
`/start` сбрасывал меню. Длинный экран возвращал только первую часть, хотя его
действия могли относиться к невидимому окончанию.

## Решение

Умение в выбранном слоте остаётся доступным для повторного подтверждения.
Награда называет следующее дело; `/обучение` открывает его, в том числе после
уже рассчитанного боя. Активный бой эта команда не завершает.

`/start` существующего героя показывает сводку поверх сохранённого экрана.
`/дело` только возвращает к нему. История содержит числовой результат изменения
героя и названия вещей; частная переписка и внутренний номер команды не выводятся.
Старые события до установки новой схемы задним числом не восстанавливаются.

Длинный экран хранится целиком. Игрок просит очередную часть сам: кнопкой либо
`/текст N`. Клавиатура действий доступна в последней части, служебные команды
остаются доступны. Новый экран заменяет старое чтение. В PostgreSQL чтение
входит в общую запись команды и переживает остановку и восстановление копии.

Миграция `0037` добавляет `player_journey` и `player_activity`. Первая хранит
посещённые этапы, маску обучения и время активности; вторая — числовые изменения
после успешной команды. Нет входящего текста, имени, поиска или частного ответа.
Общий отчёт показывает только количества. Старые персонажи исключены из группы
новичков, пока не наблюдалось создание. Перерыв в 30 минут отделяет сессию,
сутки без действия — настраиваемый признак неактивности, а не доказательство ухода.

## Проверка и границы

Сквозной автоматический маршрут проходит шесть настоящих дел. SQL проверяется
на отдельной базе: ошибка, повтор, одновременная обработка и восстановление копии.
Матрица развития отдельно сохраняет поражения и невыгодные способы заработка.
Числа и ручной протокол — в [проверке M04](../verification-m04-2026-10-08.md).
Модель и имитация Telegram не доказывают удобство для живых игроков и NVDA/JAWS.
