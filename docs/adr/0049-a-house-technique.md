# ADR 0049 — Техника дома

Статус: принято (2026-08-30)

## Обстоятельства

ADR 0047 назвал семь домов и решил, что у каждого своя **техника** — «лёгкая
механика вступления»: вступил в дом — получил доступ, ушёл — потерял. Без
механики дом остаётся перекрашенной гильдией, и вступление в него меняет только
строку в профиле.

«Лёгкая» здесь — это ограничение, а не пожелание. Игра готовится к ОБТ; новая
боевая система (эффекты, баланс, тесты, спецификации в `skill_effects.py`) —
это отдельный крупный заход, и техника дома не должна его требовать.

## Решение

**Техника — пассивный свёрток прибавок**, ровно как расовая способность
(`Race.passive`). У дома одна техника: `{ id, name, text, modifiers }`, ключи
`modifiers` проверяются по `modifiers.EFFECTIVE_KEYS`. Пока
`character.house_id == house.id`, свёрток идёт в `collect_modifiers` рядом с
расовым. Активных умений и слотов техника не трогает: движок уже считает всё, что
объявлено в `EFFECTIVE_KEYS`, и ничего нового учить не нужно.

**`content/houses.toml`** — семь домов: `id`, `name`, `seats` (два `city_id` из
`world.toml`), `technique`. Загрузчик проверяет: ровно семь домов; каждый удел —
два существующих города; ни один город не держат два дома; Гнездно не держит
никто; ключи техники — из `EFFECTIVE_KEYS`.

**Вступление.** У четырнадцати городов домов (не у Гнездна) в `services`
появляется `house`; кнопка ведёт на экран `HOUSE`. Вступают с `JOIN_LEVEL` (20) и
за `JOIN_FEE` (300 золота, уходит из игры — `economy_log.SERVICE`). Дом
эксклюзивен: `Character.house_id` — одно значение. Уйти можно бесплатно; вступить
в другой — снова взнос. Отката на смену нет (это колонка-время, которой пока
незачем быть).

**Схема.** Миграция `0022`: `characters.house_id TEXT NOT NULL DEFAULT ''`.
Персонажи начинают без дома.

**Семь техник** (первый набросок, правится по `gold_flow` и разыгранным боям, как
все числа игры — `Roadmap.md`):

| Дом | Манера | Техника |
| --- | --- | --- |
| Порубежья | скорость, натиск | инициатива +8%, урон в первый ход +8% |
| Камня | оборона, тяжёлая рука | броня +10%, получаемый урон −5% |
| Переправ | точность, терпение | точность +8%, урон дотами +12% |
| Вольной Гавани | натиск без чести | урон +6%, урон по раненой цели +10% |
| Заставы | оборона, дисциплина | запас здоровья +8%, плоская броня +30 |
| Мер | точность, магия | магический урон +8%, запас ресурса +12% |
| Курганов | точность, натиск | шанс крита +6%, урон по нежити +12% |

Порядок величин — как у сильной расовой способности (те дают 5–10% по одному
ключу; у дома два ключа послабее).

**Отложено.** Правка дома игрока из панели смотрителя (`KEEPER` — «Дом игрока»,
как «Отряд игрока»). Репутация с домом и задание при вступлении (ADR 0047 их
допускал): взнос и уровень для первого набора хватает, а репутации в игре, которая
растёт сама, пока нет (та же дыра, что закрыл ADR 0018 для `reputation_percent`).

## Что рассматривали ещё

- **Техника — активное умение в слот.** Отвергнуто: слот, ранг, откат, цель,
  спецификация в `skill_effects.py`, грань — это не «лёгкая механика», а ещё один
  класс умений на семь домов.
- **Репутация вместо взноса.** Отложено: считать её не с чего, пока в игре нет
  того, что её растит (задания домов — это акты II–V, ADR 0047).
- **Дом наследуется при новом имени.** Да, наследуется: `house_id` — из тех
  полей, что уход не трогает (ADR 0048), и вступать заново после каждого ухода
  было бы налогом на эндгейм.
