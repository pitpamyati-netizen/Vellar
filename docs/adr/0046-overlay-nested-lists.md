# ADR 0046 — Вложенные списки в правках смотрителя

Статус: принято (2026-08-30)

## Обстоятельства

Правки смотрителя (`domain/rules/overlay.py`) знают поля-скаляры (`TEXT`,
`NUMBER`, `RATE`, `FLAG`), поле-выбор (`CHOICE`), плоское перечисление (`LIST`),
«ключ=число» (`PAIRS`, ADR 0039) и «список целых» (`NUMBERS`, ADR 0040).

Осталось (Roadmap): голосования Палаты (`turning` — список ответов, у каждого
id/имя/текст), находки сбора (`Craft.yields` — список сырья, у каждого
item/уровень/биомы) и умения (`skill` — ранги, проценты, грани с вложенной
механикой). Первые два — это **список записей с несколькими полями каждая**, и
такого поля у правок ещё нет. Roadmap помечал его «спорное».

## Решение

Новый вид поля **`ROWS`**: одно поле — таблица, строка её набирается одним
сообщением, поля строки разделены `|`:

    toll_low | Брать меньше | Дешёвле — больше сделок.

Первое поле — ключ строки: та же строка с тем же ключом заменяется, новая
добавляется; нажатие по строке из списка её убирает. Ровно та же грамматика, что
у `PAIRS`, только полей в строке больше одного. Хранится всё поле одной строкой,
строки разделены `\n` (Telegram их принимает), разбирает `OverlayRecord.rows`.

`FieldSpec.row_columns` — имена колонок для подсказки и проверки; `row_required`
— сколько первых колонок обязательны.

**`OverlayKind.TURNING`** — голосование целиком: `name`, `question` (обязательно),
`text` и `options` (`ROWS`, `id | имя | текст`, минимум две, id уникальны). Флаг
`open` делает это голосование открытым (`content.open_turning_id`) — иначе
заведённое голосование не спросить.

**`Craft.yields`** — поле `yields` (`ROWS`, `item | уровень | биом, биом…`) на уже
существующей карточке ремесла. Пустой список биомов у строки — «везде», как в
файле.

**Умения — отдельный заход.** У грани не просто текст, а спецификация механики
(`domain/rules/edges.py`), и «завести грань строкой» — это либо неполная грань,
либо ещё один вложенный уровень. Скаляры умения (проценты, цена рангов) частью
лежат в `content.rules` и правятся как опорные числа (ADR 0040). `skill` остаётся
в Roadmap до отдельного решения.

## Последствия

- `FieldKind.ROWS`, `OverlayRecord.rows`, экран поля-таблицы (список строк +
  набор сообщением), проверка в `overlay.problems`;
- `OverlayKind.TURNING` — заводится и правится, ложится на `content.turnings`
  и `content.open_turning_id`; `overlay.to_toml` печатает `[[turning]]` с
  вложенными `[[turning.options]]`;
- `Craft.yields` правится с карточки ремесла; правка из панели больше не роняет
  находки (раньше `_craft_from` их только сохраняла из файла);
- `content/changelog.toml` не трогается: это инструмент смотрителя.
