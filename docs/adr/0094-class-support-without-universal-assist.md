# ADR 0094 — Помощь товарищу сохраняет роли классов

Дата: 09.10.2026. Принято по уточнению пользователя.
Отменяет универсальное прикрытие из
[ADR 0093](0093-participation-and-shared-expedition-rewards.md).
Правила провокации из [ADR 0027](0027-a-taunt-pulls-the-blow.md) сохраняются.

## Причина

При реализации M06 всем классам дали действие `/прикрыть`, создающее союзнику
барьер на 15 процентов его максимального здоровья. Оно размывало роли классов.
Требование пройти встречи разными составами не требует одинаковых защитных
способностей у каждого персонажа.

## Решение

Удалить действие из правил боя, команд и клавиатуры. Прежняя команда и старая
кнопка обрабатываются как непонятный ввод, не расходуют ход, не дают барьер
и не засчитываются участием.

Оборона самого персонажа остаётся доступна всем через `/защита`. Провокация,
лечение и остальные способы поддержки работают через существующие выученные
умения. Награды и личный зачёт по-прежнему учитывают состоявшиеся действия,
включая защиту себя и полезное умение, без требования наносить урон.

Подсказки встреч и справочники перечисляют только оставшиеся способы ответа.
Изменение не требует миграции: действие не хранится в снимке боя. Здоровье,
барьеры, участие и другие уже записанные результаты остаются читаемыми.

## Проверка

`tests/domain/test_participation_m06.py` проверяет отсутствие команды и кнопки
для восьми классов и отказ старого ввода без изменения боя. Существующие проверки
`tests/domain/test_party_and_defence.py` подтверждают самостоятельную защиту
и перевод удара провокацией. Ручная игра в Telegram и NVDA/JAWS требует отдельной
приёмки.
