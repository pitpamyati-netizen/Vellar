# ADR 0095: постоянное общее дело города

Дата: 09.10.2026. Статус: принято для реализации M07.

Уточняет [ADR 0090](0090-durable-battles-and-sessions.md) для общего города,
[ADR 0086](0086-durable-effects-and-delivery.md) для разовых наград и
[ADR 0093](0093-participation-and-shared-expedition-rewards.md) для личного участия.
Существующая сводка заставы по ADR 0053 продолжает работать отдельно.

## Решение

Первый образец — переправа у Дубно. Два общих этапа описаны в
`content/city_events.toml`: восстановление открывает снабжение, снабжение
оставляет работающую переправу. Бой и разведка используют настоящие занятия
первой локации. Ремесленная помощь использует существующий рецепт первого
ранга: сырьё расходуется, работа и личное задание засчитываются, вся партия
передаётся городу. Изделия в сумку не выдаются.

Каждый вклад даёт одну единицу. За этап один герой может дать по две единицы
каждым способом; для завершения нужно четыре. Одиночка может закончить дело
боем и разведкой без ремесла. Другие игроки помогают независимо, собственные
бои сохраняют собственную очередь. Общей очереди города и срока участия нет.

Результат каждого этапа выбирается по числу вкладов; равенство лидеров означает
совместный результат. Первый результат определяет постоянную скидку выезда:
бой — 10%, разведка — 15%, ремесло — 20%, равенство — 10%. Скидка начинает
работать после снабжения и действует для всех выезжающих из этого города.
Цена рассчитывается одинаково на экране дороги и при оплате; округление вниз.
Городские услуги, путь и обычные занятия доступны при каждой развилке.

## Сохранность

`city-event:*` хранится в `gameplay_state` PostgreSQL без срока. Новая таблица
не нужна; вершина схемы остаётся `0037`. Запись входит в существующую общую
операцию и замок SQL. Вклад, расход сырья, работа, личный зачёт, переход этапа,
награда, право на неё и ответ команды сохраняются или отменяются вместе.
В `local` остаётся временная память; долгий срок записи не делает этот режим
постоянным.

Бой даёт отдельный вклад каждому участвовавшему победителю, пока этап открыт.
Номер боя защищает от повторного зачёта. Все победители одного расчёта
проверяются относительно этапа в начале расчёта: оставшиеся участники
не переносят свой вклад на только что открывшийся этап. Когда цель уже достигнута,
обычная награда боя сохраняется, дополнительного городского права нет.
Разведка записывается только вместе с действительным расходом узла.
Ремесленная кнопка сверяет показанный этап перед расходом материалов.

За каждый закрытый этап участник получает 20 золота один раз независимо от
числа своих вкладов. Забрать можно позднее и из другого города. Постоянное
право `этап + персонаж` защищает и от нового нажатия с новым номером сообщения.
История успешных вкладов конечна: восемь записей на образец. Сводка доступна
всем через `/событие`, в городе и в сводке заставы; массовая рассылка не требуется.

Начатые идентификаторы, порядок этапов и правила нельзя менять обычной правкой
TOML. Такое изменение требует отдельного решения о переносе сохранённого мира.
Добавление других городов остаётся после ручной проверки образца.

## Доказательства и ограничения

Автоматические сценарии проверяют развилки, предел, реальный расчёт боя,
разведку, ремесло, отмену, конкуренцию, повтор, потерю подтверждения COMMIT,
чтение новым адаптером без Redis и проверенную полную копию.
Результаты — [протокол M07](../verification-m07-2026-10-09.md).
Telegram, несколько настоящих людей, NVDA/JAWS и несколько процессов
самого приложения требуют отдельной ручной приёмки.
