# Указатель документации Vellar

Рабочие инструкции — [AGENTS.md](../AGENTS.md). Вся документация использует
один порядок работы Codex; отдельного набора правил Claude больше нет.
Пути в кодовых обозначениях справочников обычно даны от корня проекта.

Действующий план — Roadmap, сведения о наличии функций — current-state,
находки на дату — аудит. Стратегия описывает желаемое; она не отмечает
запланированное как готовое. История сохраняет прежние формулировки.

## Поддержание согласованности

Меняя систему, обновлять её справочник, состояние и соответствующий пункт
Roadmap. Новое решение связывать с отменённым ADR. Исторические числа нагрузки
не переносить в текущие гарантии. Дата проверки указывает на конкретный срез,
а не на бессрочную достоверность.

На 25.09.2026 перенесены инструкции, отключён хук автокоммита, проверены ссылки
всего набора документов. Содержательные изменения затронули справочники состояния,
запуска, хранения, доступности и контента. В ADR исправлены только ссылки на
руководство; прежние решения не переписаны под новую стратегию.
