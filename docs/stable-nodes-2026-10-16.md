# Узлы без перестановок: 16 октября 2026 года

Уточнение по повторной жалобе: это исправление устранило автоматическую
перестройку, но не охватило отдельный экран возврата из боя. Он мог показывать
нулевую карту без настоящих остатков. Этот путь исправлен отдельно:
[возврат к узлу](node-return-2026-10-16.md). Приведённые ниже результаты
относятся к прежнему прогону и не доказывают проверку этого возврата.

## Исправление

Причина воспроизведена двумя проверками до изменения кода: пополнение
узлов поднимало общее поколение и полностью меняло карту. Защита кнопок
из предыдущего исправления не устраняла само правило перестройки.

Теперь карта закреплена. Выработка и пополнение не меняют названия, виды,
уровни и связи узлов; обновляется только содержимое опустевшего узла.
Чужая выработка не меняет личность ожидающей стаи и не возвращает игрока
ко входу. Прежние раскладки, включая ненулевые номера после выработки
и сбросов смотрителем, сохраняются однократно без сброса мира.

Решение — [ADR 0108](adr/0108-stable-location-layouts.md),
актуальные правила — [процедурная сборка](procgen.md).
Запись обновлений — 1.93. Явный сброс смотрителем остаётся отдельным
действием и по-прежнему создаёт следующую раскладку в PostgreSQL-режиме.

## Проверки

Полный прогон выполняется на отдельном PostgreSQL 17 с ICU `ru-RU`
на порту 55432 и Redis на порту 56379. Рабочая `.env` не меняется.

```powershell
pwsh -File scripts/m00-verify.ps1 -PgBin "C:\Program Files\PostgreSQL\17\bin" -ReportPath backups/stable-nodes-complete-verification.txt
```

Полный прогон завершился успешно на Python 3.14.6. Проверка копии сохраняет
ненулевую карту с номером 7 и волну 84; после восстановления наполнение
до волны 85 не меняет номер карты. Временные PostgreSQL и Redis остановлены,
порты 55432 и 56379 закрыты. Журналы и копии остались в игнорируемом `backups/`.

При коммите `VELLAR_SKIP_TESTS=1` исключает повтор уже завершённого набора;
проверки стиля, формата и типов в хуке остаются включёнными.

Два пропуска относятся к прежним сценариям успешного прохождения подземелий:
тестовый герой проигрывает бой. Новые проверки узлов и SQL не пропущены.
Сохранены предупреждения Pydantic о записи неизменяемых словарей;
чтение, повторное сохранение и восстановление проверяются отдельно.
