# Смотритель — служебный доступ

Смотритель — не сильный игрок, а человек, который проверяет игру. Экран
смотрителя срезает работу, которую игра иначе потребует: золото, которое
заплатил бы подряд, уровень, который принёс бы бой, раны, которые закрыла бы
ночь на постоялом дворе. Новых правил он не вводит — всё идёт через те же
функции домена, поэтому персонаж смотрителя остаётся законным персонажем.

## Кто смотритель

Решает `ADMIN_IDS` в окружении — список Telegram id через запятую:

```
ADMIN_IDS=5670700796,431112223
```

Пусто — значит смотрителей нет. Право живёт в окружении, а не в базе, по двум
причинам: его нельзя выдать себе изнутри игры, и оно переживает потерю таблицы.

Колонка `characters.is_admin` — зеркало этой настройки, чтобы экраны спрашивали
персонажа, а не конфигурацию. Она переписывается при каждой загрузке персонажа
его владельцем (`application/services/keeper.py`): id добавили — доступ появится
со следующего нажатия, id убрали — исчезнет так же быстро. Запись в базу идёт
только когда ответ изменился.

## Что он может

Кнопка «Смотритель» в главном меню видна только смотрителю. На экране:

| Кнопка | Что делает |
| --- | --- |
| Выдать золото | +1000 золота |
| Поднять уровень | ровно один уровень и очки, которые он приносит |
| Залечить раны | здоровье до максимума |
| Выдать очки | +5 очков характеристик и +5 очков умений |

Кроме экрана, смотрителю открыта дорога: в списке «Мир» видны все пятнадцать
городов независимо от уровня, а в списке локаций нет запрета по уровню. Всё
остальное — бой, ремёсла, подряды, цены — работает ровно как у игрока: в этом и
смысл проверки.

Каждое действие отвечает числом, которое получилось: смотритель сверяет игру, а
не выслушивает заверения.

## Правила, которые здесь держатся

- **Ничего не выдаётся мимо домена.** Уровень выдаётся опытом через
  `progression.grant_experience`, поэтому очки за уровень приходят из
  единственного места, где они выдаются вообще (`domain/rules/keeper.py`).
- **Экран проверяется на каждом нажатии.** Право могли отобрать между двумя
  кнопками; тогда экран отвечает «Этот экран больше не ваш» и возвращает в
  главное меню.
- **Игрок не видит и не набирает.** Кнопки нет в его клавиатуре, а набранная
  вручную надпись «Смотритель» ничего не открывает.
- **Доступность обычная.** Служебный ряд на месте, псевдографики нет, числа —
  словами; экран внесён в `tests/presentation/conftest.py::all_screens`, как и
  любой другой.
