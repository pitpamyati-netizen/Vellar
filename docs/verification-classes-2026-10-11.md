# Проверка переработки классов, 11.10.2026

Проверяется [переработка восьми классов](classes.md), выполненная по прямому
поручению пользователя. [Обзор](class-rework-sources-2026-10-11.md) содержит
десять открытых первичных источников; это обобщение принципов, а не среднее
чужих чисел урона. Исходный каталог — коммит
`60e431bf55886324343c6d2fcb2f06bba81d8ceb`.

## Что проверяют новые сценарии

- Все восемь классов имеют исполняемые условия. Проверены точная граница
  здоровья, предел 25 процентов, выбор наибольшей прибавки и фактический урон.
- Ранние характерные умения доступны с уровня 3. Перенесённое выше уровня
  героя выученное умение остаётся доступным вместе с рангом и выучкой.
- Выбор союзника отделён от врага и не расходует действие. Неверный номер,
  чужая сторона и вышедший боец отвергаются до расхода.
- Лечение, барьер, очищение и восстановление направляются товарищу. Проверены
  его собственный максимум здоровья, запрет лечения и групповая выучка.
- Команды и кнопки совпадают; сохраняются шесть номеров умений. Классовые
  прибавки в карточках совпадают с правилами; расовое умение их не обещает.
- Загрузчик отвергает неверные условия, пороги, состояния и враждебную помощь.
  Старые снимки боя и каталога читаются без новых полей.
- Настоящий обработчик `/союзник 2` записывает выбор в PostgreSQL. Новый
  экземпляр хранилища после удаления Redis-записи читает его; `/умение 1`
  лечит товарища. Повтор того же сообщения не даёт второго действия.
  Отдельно проверяется постоянный выбор противника без игрового хода.

## Сравнение каталогов

[Полные измерения JSON](class-rework-balance-2026-10-11.json) сохраняют каждый
срез, включая поражения: восемь классов × семь уровней
`1, 3, 8, 15, 30, 75, 150` × три вида противников × двадцать повторов × два
каталога = **6720 боёв**. Начальные значения генератора одинаковы.
Оба каталога работают на одном нынешнем движке: сравнивается содержимое,
а не две полные версии программы. Старые классы не имеют новых условий.

| Противники | Победы старого каталога | Победы нового каталога |
| --- | --- | --- |
| Обычные | 1120 из 1120 | 1120 из 1120 |
| Элитные | 1119 из 1120 | 1120 из 1120 |
| Боссы | 1093 из 1120 | 1092 из 1120 |
| Всего | 3332 из 3360 | 3332 из 3360 |

Сборка берёт доступное обычное оружие и доспехи, распределяет характеристики
и ставит базовые умения первого ранга. Соперники одной развилки исключены
из панели. Нет вложений в пассивные умения, выучек и специализаций; выбор
действия делает существующая приблизительная модель `build/fight`, которая
не оценивает все новые сочетания. Это контрольный срез, не предел силы героя.

Сумма побед одинаковая, но отдельные случаи изменились. Паладин уровня 150
выиграл 18 из 20 боёв с боссами вместо 13; жрец уровня 8 — 20 вместо 17.
Следопыт уровня 15 — 14 вместо 20, маг уровня 75 — 15 вместо 16.
Это видимый компромисс раннего контроля и выбора базовой панели: одинаковый
итог не означает равной силы всех сборок. Медианная длительность изменилась
от минус 3 до плюс 8,5 действия в отдельных срезах. На уровне 150 обычный
противник по-прежнему часто побеждается за 2–3 действия; это ограничение
самой игровой кривой, а не доказательство содержательного позднего боя.

Команда воспроизведения, когда прежний каталог сохранён в отдельной папке:

```powershell
uv run python -m scripts.class_rework_report --baseline-content backups/class-rework-2026-10-11/baseline-content --output docs/class-rework-balance-2026-10-11.json
```

Для сравнения из другого клона прежние `content/classes.toml` и
`content/skills.toml` берутся из указанного исходного коммита; остальные файлы
каталога копируются в ту же отдельную папку. Скрипт без `--baseline-content`
измеряет только текущий каталог.

## Общие проверки и отдельное хранилище

Проверки выполняются на Python 3.14 с закреплёнными зависимостями. PostgreSQL
слушает только `127.0.0.1:55432`, Redis — `127.0.0.1:56379/0`; процесс проверки
получает отдельные `VELLAR_TEST_POSTGRES_DSN` и `VELLAR_TEST_REDIS_DSN`.
Рабочая `.env` и данные игроков не изменяются.

Полный порядок: `scripts/m00-verify.ps1` с PostgreSQL 17. Он включает стиль,
форматирование, типы, обычные и интеграционные тесты, покрытие домена,
миграции, сохранение и восстановление отдельных баз, перенос версии 0030
к 0038 и нагрузку двадцати тестовых игроков. Завершающий прогон завершился
с кодом 0; отчёты сохранены локально в
`backups/class-rework-2026-10-11/complete.txt` и `complete-console.txt`.

Всего прошли 3188 разных тестов. Повторный прогон для покрытия в эту сумму
не включён. После последних уточнений текста отдельно повторены проверки
экранов, участия и списка обновлений. Пробная нагрузка — один успешный прогон
указанного профиля, а не гарантия задержки в живой игре.
Временные PostgreSQL и Redis остановлены; порты 55432 и 56379 закрыты.

В модели совместного спуска три состава дают медленному товарищу возможность
сделать действие перед последним ударом. Это согласованное прохождение,
а не обещание личной награды без участия. Ожидание реализовано обычной защитой;
условия награды, поражения и запрет универсального прикрытия не изменены.
