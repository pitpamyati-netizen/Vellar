# Руководство по содержимому

Всё содержимое игры лежит в `content/*.toml`. **Добавить расу, класс, черту, вещь или
город можно без единой правки кода.** Загрузчик
(`src/mmorpg/infrastructure/content/loader.py`) разбирает эти файлы один раз на старте
и громко падает с полным списком бед: на испорченном содержимом бот не поднимается.

| Файл | Что в нём |
| --- | --- |
| `world.toml` | 15 городов, по 5 локаций, полосы уровней, условия открытия |
| `races.toml` | 16 рас: прибавки, пассивная способность, ссылка на расовое умение |
| `classes.toml` | 8 классов: ключевые характеристики, кривые ресурса и здоровья, опорные числа |
| `traits.toml` | 64 черты, словарь прибавок, категории |
| `skills.toml` | по 24 боевых (изучаемо 20) и 20 пассивных на класс, 1 боевое на расу, по две грани у каждого |
| `items.toml` | виды снаряжения, ступени, редкости, расходники, сырьё |
| `crafts.toml` | собирающие и делающие ремёсла, рецепты, правила ранга и качества |
| `turnings.toml` | вопросы Большого совета, открытый назван в `[meta].open` |
| `houses.toml` | семь домов: два города каждый, техника дома свёртком прибавок |

## Общие правила

1. **Черты и снаряжение не дают боевых умений.** Только прибавки; снаряжение может
   ещё усилить конкретное умение через `skill_modifiers` (`docs/skills.md`).
2. **Словарь прибавок один.** Черты, пассивные умения и снаряжение берут из
   `traits.toml [meta].modifier_keys`. Ключ, которого там нет, отвергается.
3. **Размер панели постоянен.** 6 боевых слотов и 1 расовый; пассивное умение слота не
   занимает вовсе (ADR 0016).
4. **Видимый игроку текст — русский, всё остальное — английский.**
5. **Никакой псевдографики ни в одном текстовом поле.** Числа словами:
   `"выше на 15 процентов"`.
6. **Раса, класс и ремесло — три разные вещи.** Раса говорит, кто такой приключенец,
   класс — как он дерётся, ремесло — что он делает за плату, и ремёсла живут в
   `crafts.toml` и больше нигде. Классу нельзя сползти в ремесло или в чёрный список из
   `Narrative.md`, раздел 2; держит `tests/content/test_naming.py`.

## Добавить расу

```toml
[[race]]
id = "seaborn"                       # snake_case, уникально, не меняется никогда
name = "Морской народ"               # одно-два русских слова, <= 20 букв
description = "Одна фраза: какие они и что это даёт в дороге."
bonuses = { AGI = 2, WIS = 1, STR = -1 }
passive = { id = "tide_born", name = "Приливная выучка", text = "Одна фраза об эффекте.", modifiers = { dodge_percent = 5 } }
active = "race_seaborn_undertow"     # обязано существовать в skills.toml
```

**У пассивной способности обязаны быть `modifiers`, и каждый их ключ обязан быть
таким, который движок читает** (`modifiers.EFFECTIVE_KEYS`, ADR 0018). Раса без них не
загружается. `text` говорит ровно то, что делают прибавки, в числах. Идентификатор
заморожен с той минуты, как его выбрал первый персонаж: переименование — это правка
`name`/`description`, а не смена ключа.

Бюджет держит `tests/content/test_races_classes_skills.py`: положительных очков не
больше `3 + (сумма штрафов)`, чистая сумма не больше `+3`. `{ STR = 2, END = 2,
INT = -2 }` законно, `{ STR = 4 }` — нет.

Потом добавьте расовое боевое умение в `skills.toml` с `owner = "race:seaborn"`,
`kind = "active"`, `level = 1` и ровно двумя гранями, и поднимите `EXPECTED_RACES` в
загрузчике и в тесте: счёт проверяется нарочно.

## Добавить класс

```toml
[[class]]
id = "monk"
name = "Монах"                       # одно русское слово: как персонаж дерётся
role = "Ближний бой без оружия"
description = "Одна фраза."
key_stats = ["AGI", "WIS"]
weapons = ["staff", "dagger"]        # идентификаторы из items.toml [meta].weapon_types
armor = ["cloth"]                    # ровно один род из items.toml [meta].armor_types
bonuses = { AGI = 2, WIS = 1 }
resource = { id = "chi", name = "Ци", base = 55, per_level = 1.2, stat = "WIS", per_stat = 1.5, regen_per_turn = 8 }
health = { base = 95, per_level = 7.5, per_endurance = 6.0 }
```

`weapons` и `armor` — это класс в руках игрока. Оба списка обязательны и обязаны
называть роды, которыми хотя бы одна вещь в `items.toml` и правда является: классу,
которому нечего надеть, придётся драться голыми руками в рубахе. **Доспех у класса
один** (ADR 0064): ткань — маг и жрец, кожа — разбойник и друид, кольчуга — варвар и
следопыт, латы — воин и паладин. Это не запрет: чужое надевается, но стоит точности и
инициативы (`equipment.proficiency_penalty`).

Классу нужны ровно **24 боевых** и ровно **20 пассивных** умений на тех уровнях, что
перечислены в `classes.toml [meta].active_unlock_levels` / `passive_unlock_levels`.
Боевых написано 24, а изучить можно 20: на четырёх уровнях из `[meta].fork_levels`
стоит развилка. Загрузчик проверяет и число, и точную последовательность уровней.

## Добавить ремесло или рецепт

```toml
[[craft]]
id = "fishing"                       # snake_case, уникально, не меняется никогда
name = "Рыбная ловля"                # как называется работа, по-русски
kind = "gathering"                   # или "making"
stat = "LCK"                         # характеристика, на которую опирается работа
description = "Одна фраза о работе."

[[family]]                           # лестница: по ступени на каждые два ранга
id = "fish"
name = "рыба"
gathered_by = "fishing"              # чьи это находки; без него лестницу делают
biomes = ["река", "берег", "море"]   # где она лежит, общее для всех ступеней
grades = [
    { item = "river_fish", rank = 1, level = 1 },
    { item = "sea_fish", rank = 5, level = 46 },
]

[[line]]                             # работа: пишется один раз, идёт по всем рангам
id = "cook_stew"
craft = "cooking"
output_family = "stew"               # или gear = "medium_body" + rarity = "common"
inputs = [{ family = "fish", count = 2 }, { family = "herb", count = 1 }]
experience = 10                      # за ранг: на ранге r запишется experience * r
```

Собирающему ремеслу нужна хотя бы одна лестница с `gathered_by`, начинающаяся с
первого уровня; делающему — хотя бы одна работа, открытая с первого ранга. Работа
выпускает только то, что уже есть в `items.toml`: ступень снаряжения — из
`[meta].rank_tiers`, ступень сырья — из лестницы. Стоить сделанное обязано больше
своего сырья на каждом ранге (`tests/content/test_crafts_content.py`). Штучное пишется
как `[[recipe]]` с прямыми `inputs` и `output`. Ранги, размеры сбора и три ступени
качества живут в `crafts.toml [meta]`.

У нового собирающего ремесла обязан быть свой инструмент — запись в `items.toml
[meta].tool_types` с `craft = "fishing"` и своим `sources`, и `[[gear]]` под неё
(ADR 0056). См. `docs/crafts.md`.

## Добавить умение

```toml
[[skill]]
code = "monk_palm_strike"      # уникально среди всех умений
name = "Удар ладонью"          # уникально внутри владельца — кнопки ведут по тексту
owner = "class:monk"           # "class:<id>" или "race:<id>"
kind = "active"                # или "passive"
level = 1                      # обязан совпасть с расписанием для своего вида
cost = 10                      # проценты запаса; только боевое
cooldown = 0                   # в ходах; только боевое
target = "enemy"               # self | enemy | all_enemies
effect = "damage"              # обязан быть в skills.toml [meta].active_effects
power = 135                    # ПРОЦЕНТ на первом ранге — см. ниже
scaling = "AGI"                # чем меряется обычный удар
tag = "precision"              # press | guard | precision — необязательно
weapons = ["staff"]            # без такого оружия не срабатывает — необязательно
requires_stealth = true        # бьёт только из незаметности — необязательно
text = "Одна фраза, что делает умение."
edges = [
    { name = "Первая грань", text = "Что меняется." },
    { name = "Вторая грань", text = "Что меняется иначе." },
]
```

`weapons` — это то, что умению нужно в руке. Не назван — умение работает с чем угодно.
Список вправе быть только *уже* того, что носит класс (`classes.toml`): более широкий —
это кнопка, которая не сработает никогда, и загрузчик её не пропускает.

Пассивное умение вместо этого объявляет `effect` **ключом прибавки**
(`effect = "armor_percent"`, `power = 6`) и не пишет
`cost`/`cooldown`/`target`/`scaling`.

**`power` никогда не бывает абсолютным числом.** Это процент от того, что и так растёт
вместе с персонажем (урон — от броска оружия, лечение и барьеры — от максимума
здоровья, усиления — от самого модификатора), поэтому умение, написанное один раз,
верно на всей полосе. Шкала урона: открывающий удар без отката 130, удар с откатом
170–200, умение по всем 110–150 *на цель*, венчающее 210–275. Абсолютное число здесь —
единственная ошибка, которую не поймает тест (ADR 0007, `docs/skills.md`).

`tag` необязателен и нужен, только когда эффект оставил бы не тот след или когда класс
иначе не добрался бы до всех трёх тегов (напор, заслон, финт) — а добраться обязан
каждый. У каждого умения ровно две грани; их коды выводятся как `<code>_a` и
`<code>_b`. Новое значение `effect` означает и запись в `[meta].active_effects`, **и**
реализацию в боевом движке.

## Добавить черту

```toml
[[trait]]
id = "stone_patience"
name = "Каменное терпение"
category = "defense"                 # одна из traits.toml [meta].categories
tags = ["броня", "выносливость"]     # свободные, показываются в фильтрах
modifiers = { armor_percent = 8, initiative_percent = -4 }
text = "Броня выше на 8 процентов, инициатива ниже на 4."
```

Черты категории `dark` обязаны нести и выгоду, и настоящий штраф; направление решает
`[meta].lower_is_better`.

## Добавить вид снаряжения

Снаряжение **руками не пишут**: пишут *вид*, а вещь собирается из вида, ступени,
редкости и оттиска — так же, как противник собирается из породы и уровня (ADR 0015,
ADR 0059).

Ступеней семнадцать, и они привязаны к городам: четыре ранние в стартовом городе,
дальше по одной на входе почти в каждый следующий (`world.toml`, `level_min`,
ADR 0052). Новую ступень добавляют в `[meta].tiers` строкой с прилагательным в четырёх
родах; загрузчик держит первую на уровне 1 и не пускает две на один уровень.

```toml
[[gear]]
id = "halberd"                       # snake_case, уникально, не меняется никогда
noun = "алебарда"                    # существительное, из которого строится имя
gender = "f"                         # m | f | n | p — «Крепкая алебарда»
slot = "weapon"                      # weapon/head/body/hands/feet/trinket
weapon_type = "spear"                # только оружие, из [meta].weapon_types
```

Доспех вместо этого объявляет `armor_type`, а оберег — ни того ни другого. Имя
строится как **прилагательное ступени + существительное + слово ведущего аффикса +
пометка редкости**: «Крепкая алебарда ярости редкой работы» (ADR 0059). Все части
приходят из `[meta]`, и загрузчик не пропускает ступень, у которой нет прилагательного
для одного из четырёх родов.

Урон, броня, характеристики и цена **тоже не пишутся**. Они приходят из `[meta]`:

- `weapon_types[].damage_type` — **чем бьёт род**: копьё колет, меч рубит, булава
  дробит, жезл бьёт чарами. Обязательно: обычный удар героя берёт род отсюда, и по нему
  считаются сопротивления цели. Пятнадцать родов — в `domain/entities/damage.py`.
- `weapon_types[].dice` — **среднее** рода на первой ступени и форма броска (`"2d6"`).
  Среднее растёт со ступенью.
- `weapon_types[].spread` — **характер** рода: во сколько раз верх удара выше низа. У
  меча 1,2, у булавы 1,5, и выше 1,5 не поднимается никто — это потолок всей игры
  (`dice.MAX_SPREAD`). **Плоскую часть не пишите**: она считается из среднего и размаха
  (ADR 0020).
- `armor_types[].armor` — доля брони относительно кожаного, а `slots[].armor_share` —
  сколько место закрывает вообще.
- `rarities[].affixes` — сколько прибавок несёт вещь этой редкости: 0/1/2/3/4, и у
  двух старших одна из них — особое свойство (ADR 0059). `durability` — сколько сборов
  держит инструмент (ADR 0056), `toughness` — во сколько раз прочнее снаряжение
  (ADR 0057). **Реликвия** считается от уровня *героя* и растёт вместе с ним.

## Добавить расходник или сырьё

```toml
[[item]]
id = "sea_glass_vial"
name = "Склянка морского стекла"
kind = "consumable"                  # consumable | material — никогда не снаряжение
slot = "none"
rarity = "rare"                      # из items.toml [meta].rarities
level = 18
price = 760
stack = 10
effect = { kind = "heal_percent", power = 30 }
```

**У вещи нет описания.** Что вещь такое, отвечают её род, ступень и числа. Поле
`text` загрузчик отвергает, как и написанное руками `kind = "equipment"`.

`effect.kind` у расходника — ветка в `combat._use_item`: `heal_percent`,
`restore_resource_percent`, `cleanse`, `buff_damage_percent` действуют на выпившего,
`flashbang` — на всех врагов сразу (ADR 0043). Новый род расходника — новая ветка там,
а не поле у вещи.

Сырьё объявляет `source` — какого оно рода: `руда`, `травы`, `волокно`, `шкуры`, `рыба`
или `древесина`. Делаемое сырьё — слиток, кожа, ткань, брус — `source` не несёт вовсе
(ADR 0062). Тем же словом инструмент говорит, что он берёт (`tool_types.sources`).
Названная жила отдаёт только свой род (`adventure.GATHER_SOURCES`), безымянная — то,
что берёт инструмент в руках; сырьё без `source` выдавал бы любой узел подряд, и
`tests/content` этого не пропускает.

Всё, что называет вещь по имени — награда задания, выход рецепта, таблица добычи, —
пользуется собранным именем: `reward_item = "light_feet@9#rare"`. **Реликвия** вправе
быть наградой только задания, завершающего цепочку из четырёх и больше.

## Добавить или перебалансировать город

```toml
[[city]]
id = "seaward"
order = 16
name = "Приморье"
description = "Одна фраза."
level_min = 140
level_max = 150
unlock_level = 140
unlock_requires = ["city:last_beacon"]
services = ["shop", "locations", "dungeons", "tavern", "summary", "mentor", "bank", "forge", "arena", "house", "chamber"]

[[city.dungeon]]
id = "shell_ways"
name = "Ракушечные ходы"
flavour = "Одна фраза о том, что это за место и почему туда лезут."
biome = "затопленные ходы"
level = 143

[[city.dungeon]]
id = "shell_deep"
name = "Основание Рифа"
flavour = "Одна фраза."
biome = "глубокие пещеры"
level = 150
deep = true

[[city.location]]
id = "shell_shore"
slot = 1
name = "Ракушечный берег"
biome = "берег"
level_min = 140
level_max = 142
```

`[[city.dungeon]]` — список названных подземелий города (ADR 0041): не меньше четырёх
обычных вразброс по его полосе и ровно одно `deep = true` на `level_max`. `id` —
замороженный ключ (кормит сид захода). `biome` — из dungeon-ростера (`enemies.toml`,
`dungeon = true`): шесть подземных биомов (`рудник`, `штольни`, `катакомбы`, `глубокие
пещеры`, `затопленные ходы`, `подземный город`). `unlock_level` необязателен (0 —
открыт вместе с городом); глубокое открывает дошедший до последней локации.

Инварианты, которые проверяет `tests/content/test_world.py`: ровно 15 городов и ровно
5 локаций на город (места `1..5` по порядку); у каждого города ровно одно
`deep`-подземелье с `level == city.level_max` и не меньше четырёх обычных; id
подземелий уникальны глобально; внутри города обе границы растут от локации к локации
без пробела, первая начинается на `level_min` города, последняя кончается на его
`level_max`; полосы городов перекрываются; каждый уровень от 1 до
`max_character_level` покрыт хотя бы одной локацией.

Полосы уровней локации решают уровень противников, качество и редкость добычи, опыт и
тяжесть событий; сама карта собирается и не хранится (`docs/procgen.md`). У
**подземелья** свой фиксированный `level`, а не уровень игрока: содержимое, всегда
ровно по игроку, платит как свежий вызов вечно (ADR 0019).

## Породы противников

`content/enemies.toml`. Кроме множителей, порода может объявить **`element`** — род
урона, которым она бьёт: четыре физических (`piercing`, `slashing`, `bludgeoning`,
`rending`) и одиннадцать магических (`arcane`, `fire`, `cold`, `poison`, `acid`, `air`,
`holy`, `light`, `mental`, `nature`, `negative`). Не назван — решает порода: зверь
рвёт, гуманоид рубит, нежить бьёт `negative`, стихия — `arcane`, тварь — `mental`.

Сопротивления цели считаются по этому роду **и** по его половине:
`resist_piercing_percent` и `resist_physical_percent` складываются, а не заменяют друг
друга. Ни `elemental`, ни `chaos` нет (ADR 0022).

**`dungeon = true`** уводит породу в отдельный пул: она встречается только в городских
подземельях (по `Dungeon.biome`). У каждого dungeon-биома обязано быть ≥ 3 таких
кандидата плюс `*`-запас (ADR 0042).

**`[[affix]]`** — прозвища-модификаторы врагов: приставка к имени, множители
(запекаются как `stakes`) и механика. Полностью — `docs/affixes.md`.

## Добавить задание

`content/quests.toml`. Задание — оплаченная работа: цена названа в первых двух фразах,
отказ — всегда кнопка (`Narrative.md`, раздел 4).

```toml
[[quest]]
id = "farhold_tallies"     # замороженный ключ: он лежит в журнале персонажа
city = "farhold"           # кто выдаёт и куда сдавать
level = 1                  # ниже этого уровня не предлагается
follows = ""               # не появляется на доске, пока то задание не оплачено
name = "Столбы на Тракте"
giver = "Довен, писарь заставы"
intro = "Стоит у столба со сводкой."          # до 140 знаков

                           # craft: идентификатор запрашиваемой вещи

```

Что считает каждая цель (`domain/rules/quests.py`): `kill` — побеждённых противников,
сужая по породе; `elite` — только сильных; `search` — узлы, отработанные без боя;
`craft` — то, что вышло из работы, и никогда купленное. Счётчик не убегает за свою цель
и двигается только по взятому заданию.

**Говорите где.** `location` превращает «обойдите три места» в «город Дубно,
„Локации“, „1. Луга у Заставы“»; без него экран показывает только на город целиком.
Ставьте его всему, что случается в дороге, и никогда — `craft`.

существует, цепочка не замыкается в круг, уровень лежит внутри полосы города, задание
не платит меньше того, за которым идёт, и ничто не говорит словами из чёрного списка
`Narrative.md`.
